# Prompt Jury v0.3.0 Phase 4 Web Judge

Status: Implemented; browser acceptance testing pending  
Scope: ChatGPT Web Judge with extension-owned Temporary Chat sessions

## Official product behavior

OpenAI currently documents Temporary Chat as a new chat mode enabled by the pill-shaped Temporary control in the top-right of the ChatGPT page. Temporary chats do not appear in history and do not use or create memories, although enabled custom instructions still apply. See the [official Temporary Chat FAQ](https://help.openai.com/en/articles/8914046-temporary-chat-faq).

Prompt Jury activates the documented UI control rather than depending on an undocumented Temporary Chat URL parameter.

## Architecture

```text
ChatGPTWebJudgeProvider
  → BrowserJudgeSessionManager
    → Background Service Worker
      → create extension-owned ChatGPT tab
      → inject/activate Temporary Chat
      → persist ownership in chrome.storage.session
      → send anonymous Judge prompt
      → extract response through ChatGPTAdapter
      → verify ownership and close tab
  → parse and validate canonical JudgeResult
```

## Session guarantees

- A new background ChatGPT tab is created for each Web Judge run.
- The Temporary Chat UI must be positively confirmed before a prompt is sent.
- Failure to locate or confirm Temporary Chat closes the new tab immediately.
- Session ownership is stored in `chrome.storage.session`, surviving service-worker suspension.
- Judge prompts use a dedicated message with a 500,000-character limit.
- Every Judge prompt and close request must match the stored session ID and tab ID.
- Prompt Jury refuses to close tabs whose ownership cannot be verified.
- The temporary tab is closed after success, send failure, or parse failure.
- A cleanup failure produces a typed error asking the user to close the tab manually.

## Judge behavior

- `JudgeRunner` blinds and shuffles candidates before the Web Provider receives them.
- ChatGPT receives the same hardened Judge prompt and canonical schema used by the API Judge.
- Extracted Markdown-fenced or plain JSON is normalized, validated, and reweighted locally.
- Web Judge availability currently requires an open, signed-in ChatGPT page.
- Synthesis-only mode remains outside the evaluation Provider contract.

## Error coverage

- ChatGPT page unavailable or signed out;
- temporary tab creation or loading timeout;
- Temporary Chat control missing;
- Temporary Chat activation cannot be confirmed;
- content-script injection failure;
- response generation timeout;
- response extraction or JSON validation failure;
- session ownership mismatch;
- temporary tab cleanup failure.
