# Prompt Jury v0.3.0 Phase 5 UI Integration

Status: Implemented; live ChatGPT Web Judge acceptance testing pending  
Version: 0.3.0

## Side Panel integration

The existing AI Judge section now exposes two providers:

- OpenAI-compatible API;
- ChatGPT Temporary Chat.

Both paths run through the same Phase 2 `JudgeEngine` and `JudgeRunner`. The Side Panel no longer performs its own candidate anonymization or calls the API Judge directly.

The UI includes:

- bilingual provider names and usage descriptions;
- provider radio selection;
- API Settings access;
- provider-specific progress messages;
- bilingual typed error mapping for Web Judge availability, session creation, cleanup, and invalid output;
- ranking, confidence, score details, strengths, weaknesses, risks, unsupported claims, consensus, and disagreements;
- the current Judge provider/model;
- saved Judge run count;
- selection between multiple saved Judge results;
- synthesis mode selection and previously generated synthesis results.

## Judge execution flow

```text
EvaluationBundle responses
  → JudgeInput
  → selected JudgeProvider
  → JudgeEngine + JudgeRunner
  → private identity mapping + validated JudgeResult
  → append Judge run
  → IndexedDB
  → result UI / synthesis / export
```

API Judge requires the API configuration from Settings. ChatGPT Web Judge requires an open, signed-in ChatGPT page and creates its own Temporary Chat tab. The existing synthesis feature continues to use the configured API for both types of Judge result.

## Storage migration

IndexedDB is upgraded from version 4 to version 5 with a new `judgeRuns` store:

- `judgeRuns` has a non-unique `by-run-id` index;
- every new Judge execution appends a result;
- the latest result is the default active result;
- users can inspect earlier results from the Side Panel;
- Markdown and JSON exports include all Judge runs;
- delete-run removes both legacy and new Judge records;
- the legacy `judgeResults` store is retained for v0.2.8 compatibility;
- old single Judge results are exposed as a one-item `judgeRuns` collection when read.

No API Key or Judge configuration is copied into IndexedDB.

## Version and documentation

- English and Chinese README files document both Judge providers, Web Judge tab behavior, multi-run persistence, synthesis API dependency, and data flow.
