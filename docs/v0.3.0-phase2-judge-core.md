## Behavioral guarantees

- Provider IDs must be unique.
- Unknown and unavailable providers return typed `JudgeEngineError` codes.
- Evaluation and full modes require at least two candidate responses.
- At least one evaluation weight must be greater than zero.
- Candidate order is randomized before evaluation.
- The Judge Provider receives only `Answer A/B/...`, `provider: "anonymous"`, and content.
- Original response, provider, and model identity is returned separately in a private mapping.
- Every provider result is validated against the canonical Zod schema.
- Provider failures are wrapped without exposing provider-specific internals to callers.
- Run outcomes include provider metadata and elapsed time.

## Compatibility

The existing v0.2.8 Judge result is retained as the canonical internal result because it contains more information than the v0.3.0 example schema. Existing API Judge, UI, exports, and stored history are unchanged in Phase 2.
