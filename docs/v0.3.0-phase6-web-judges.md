# Prompt Jury v0.3.0 Phase 6 Web Judges

Status: Implemented; signed-in browser acceptance testing required for each account/site variant
Version: 0.3.22

## Scope

Phase 6 adds Gemini, Kimi, and Doubao to the Web Judge selector. All four Web Judges share the same provider-neutral evaluation, JSON repair, persistence, and cleanup flow.

## Temporary-session requirement

Prompt Jury uses a fail-closed policy:

1. An already open, signed-in provider tab is required.
2. The tab is duplicated and owned by the extension.
3. The duplicate is focused and navigated to the provider's new-chat route.
4. A temporary or incognito control must be found, clicked, and positively confirmed.
5. No Judge prompt is sent before confirmation.
6. The owned tab is closed after success or failure, and the original tab and window are restored.

Gemini officially supports Temporary Chat on the web for eligible personal Google Accounts. See [Use Gemini Apps](https://support.google.com/gemini/answer/13275745?hl=en). Google states that work and school accounts do not currently support this feature.

No official Kimi or Doubao documentation confirming a web temporary-chat feature was found, and the tested pages expose no temporary/incognito control. Both Temporary Chat Judges are therefore marked unavailable. An extension-owned tab alone is not treated as temporary because closing a normal tab may leave server-side history. Doubao additionally documents that deleting a chat does not necessarily delete memory derived from that chat.

## Implementation

- `TemporaryWebJudgeProvider` supplies the common Web Judge lifecycle and one automatic JSON-format repair attempt.
- ChatGPT, Gemini, Kimi, and Doubao expose provider-specific IDs and display names.
- The background service worker duplicates a matching signed-in tab, focuses its window, navigates to a clean route, verifies ownership, and restores the original UI after cleanup.
- The content layer uses provider-aware temporary or incognito labels and requires an explicit active state or temporary-mode status marker.
- Gemini activation is confirmed by its `temp-chat-on` control state or the active close icon, matching the current Angular web UI.
- The Side Panel provides bilingual options and platform-specific safety guidance.

## Acceptance testing

- ChatGPT: verified against the user's Chinese UI variant.
- Gemini: requires Chrome testing with an eligible personal Google Account; the documented Edge content-script restriction remains applicable.
- Kimi: marked unavailable because no verifiable temporary mode exists.
- Doubao: marked unavailable because no verifiable temporary mode exists.

If a provider rejects session creation, capture the diagnostic payload shown in the Side Panel. It contains page URL, matching control state, and dialog text, but not the candidate answers.
